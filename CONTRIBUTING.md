# Contributing

Keep ResumeRec focused: a simple offline menu-bar recorder with pause/resume and an optional webcam.

For bugs, include the app version, macOS version, Mac chip, source type, resolution/frame rate, webcam/audio settings and reproduction steps. Avoid posting private recordings, device identifiers or personal paths.

Discuss larger features in an issue before implementing them. Small fixes can be proposed directly in a pull request. Keep app-authored interface text in English, preserve saved preferences and source/device refresh on opening, and test changes at the supported 440 × 640 point settings size.

Run checks relevant to your change as described in DEVELOPMENT.md. For capture or export changes, run the synthetic media test and describe the real-device checks performed. For layout changes, verify scrolling and control access. State any checks you could not run.
