# Changelog

## 0.2.8-beta.2

- Removed the rectangular focus border from the settings tabs; the active tab keeps its blue underline.
- Keyboard focus follows the activated tab, with keyboard navigation preserved.
- App build number: 11.

## 0.2.8-beta.1

First public preview of ResumeRec for Apple Silicon and macOS 26+.

- Screen, window or region recording with pause/resume and automatic MP4 saving.
- Optional webcam with life-size preview, adjustable appearance and drag positioning.
- System audio and selectable microphone input.
- Source/device selection that refreshes on opening.
- Configurable shortcuts, countdown, codec, resolution, frame rate and capture bitrate.
- Compact vertical settings with a refined header and navigation.
- RR app icon and monochrome menu-bar template.
- Recovery of completed session segments.

This beta is ad hoc signed and not notarized. See the README for installation instructions and current limitations.
